# MastCode Asset Directory

This directory contains local image assets for the MastCode website.

## Files

- `mastcode-logo.png` - MastCode brand logo/flame icon
- `ceo-rakshitha.jpg` - CEO/Founder portrait
- `mastcode-og.png` - Open Graph image for social sharing

## How to Add Images

1. Place your image files in this directory
2. Reference them using local paths: `/images/filename.png`
3. Do NOT use Lovable cloud URLs (`/__l5e/assets-v1/...`)

## Image Optimization

All images should be:
- Optimized for web (compressed)
- Appropriate size for their use case
- Responsive-ready (source files should be high quality)
